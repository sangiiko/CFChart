## What changed

- A clearer popup puts today's progress and the next recommended problem first. The full dashboard now has its own practice and progress layout.
- Recommendations show why a problem was chosen. Result recording is available after opening the outcome section.
- The in-page rating view distinguishes official Codeforces history from model estimates and shows the model range and data status plainly.
- The toolbar tracker and problem outcome controls use the same restrained visual style as the problem timer.
- Saving a problem outcome now pauses the visible timer only after the result is stored successfully.

Firefox and Chrome packages are attached. Firefox installations using automatic updates can move from 2.0.8 to 2.0.9.
