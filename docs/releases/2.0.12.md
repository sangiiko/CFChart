## What changed

- Upgraded the local practice recommender with 8D algorithmic concept embeddings (`semantic.ts`), Empirical-Bayes difficulty- and contest-calibrated problem quality scores (`catalog.ts`), difficulty-adjusted IRT topic skill and uncertainty estimation (`skill.ts`, `state.ts`), DSR/FSRS review urgency ranking (`retention.ts`), and multi-tag session diversity penalties (`scheduler.ts`, `index.ts`).
- Optimized first-attempt feature construction (`features.ts`) with precomputed 64-bit tag bitmasks and cached tree artifact validation (`inference.ts`), plus full episode-level Python/TypeScript parity verification (`ml/recommender/parity_audit.py`).
- Automatically synchronizes past practice ledger records (`assignments`, `events`, and pinned daily plan items) to the updated catalog metadata, calibrated quality scores, shadow acceptance predictions, and subsequent Codeforces solves.
- Starting or resuming a problem timer on a new tab now automatically pauses any running timer session on another problem in the local ledger.

Firefox and Chrome packages are attached. Firefox installations using automatic updates can move from 2.0.11 to 2.0.12.
