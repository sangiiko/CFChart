## What changed

- Fixed the toolbar popup collapsing into a narrow, vertically clipped sliver. The popup is sized from its content, so its viewport-relative width (`100vw`) measured a near-zero viewport; the root now keeps a fixed 380px width.
- Added a regression test that rejects viewport units on the popup root, so the collapse cannot silently return.

Firefox and Chrome packages are attached. Firefox installations using automatic updates can move from 2.0.12 to 2.0.13.
