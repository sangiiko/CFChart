## What changed

- Overhauled the independent review (`revisit`) lifecycle (`retention.ts`, `eligibility.ts`, `index.ts`, `dataBroker.ts`):
  - Strictly caps surfaced scheduled reviews to at most **1 per day** (`MAX_DAILY_REVIEWS = 1`) and stops pushing additional reviews on the same day once today's review has been completed, snoozed, or dismissed.
  - Prevents due reviews from leaking into the regular daily-goal candidate selector (`selectRecommendationsV2`).
  - Graduates scheduled reviews permanently when an earlier assisted solve is followed by either an `'independent'` self-report, a subsequent-day Codeforces `'accepted'` submission, or an explicit dismissal (`'already-solved'`), while ignoring same-session API submission echoes (`< 12h`).
- Added direct review action controls (`Mark reviewed`, `Snooze 7d`, and `Dismiss`) to `revisit` recommendation cards (`PracticeRecommendations.tsx`) and added an `Independent review` mode with `Dismiss review` and unlocked `Solved with help` rescheduling on Codeforces problem pages (`ProblemVerdictBar.tsx`, `controller.tsx`).

Firefox and Chrome packages are attached. Firefox installations using automatic updates can move from 2.0.13 to 2.0.14.
