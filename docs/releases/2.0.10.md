## What changed

- Outcome controls now appear on a problem page only after the tracked account has an accepted submission. They also appear when an accepted verdict arrives while the page is open.
- Recommendation cards now focus on choosing and opening a problem, with outcome recording removed from those cards.
- The problem timer remains available before acceptance.
- The timer remembers your last chosen countdown duration for new problems, including after a refresh or opening a new tab. Existing problem timers keep their own duration.
- Timer sessions can record pauses, resumes, and explicit hint use in the local practice ledger.
- Displayed recommendations are logged separately from generated assignments. Practice data export includes a descriptive join between impressions, later outcomes, and research-only acceptance predictions.
- The shadow prediction does not change the live ranking; it predicts historical acceptance on self-selected attempts and is not an independent-solve probability.

Firefox and Chrome packages are attached. Firefox installations using automatic updates can move from 2.0.9 to 2.0.10. If you already installed 2.0.10, reinstall the updated package to get these changes; Firefox does not automatically reinstall a changed package with the same version.
