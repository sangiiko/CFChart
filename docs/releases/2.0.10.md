## What changed

- Outcome controls now appear on a problem page only after the tracked account has an accepted submission. They also appear when an accepted verdict arrives while the page is open.
- Recommendation cards now focus on choosing and opening a problem, with outcome recording removed from those cards.
- The problem timer remains available before acceptance.

Firefox and Chrome packages are attached. Firefox installations using automatic updates can move from 2.0.9 to 2.0.10.
