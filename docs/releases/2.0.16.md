## What changed

- Overhauled daily problem recommender calibration and session balance:
  - Replaced linear skill adjustment with a regularized MAP Logistic IRT estimator (`skill.ts`) that learns from `Solved with help` (`assisted`), `independent`, and `timeout` self-reports—and no longer discards legitimate 31–45+ minute independent solves.
  - Discounted assisted-only Codeforces AC submissions from public topic mastery (`state.ts`) so editorial-assisted solves don't hide topic weaknesses.
  - Shifted from flat `+100` targeting to a balanced deliberate-practice session (`candidates.ts`, `scheduler.ts`, `index.ts`): **Core** problems near your calibrated independent level (`theta - 40` / `tagTheta`) presented first for traction, paired with **Stretch** (`theta + 100`) or recent **Upsolve** tasks second for growth, with default daily budget scaling (`dailyTarget * 35`) so 2-problem Core + Stretch days fit cleanly.
- Improved review spacing, topic variety, and low-energy day support:
  - Adjusted initial independent review interval from 3 days to **6 days** (`4 days` on repeat lapses) to avoid verbatim short-term recall while keeping the 1 review/day cap (`retention.ts`).
  - Added 3-day 8-D concept overlap cooldown (`recentConceptOverlapPenalty` in `semantic.ts`) to prevent consecutive days of repetitive ad-hoc/constructive/math clusters.
  - Added a one-click **Light day** toggle in the Codeforces top-bar pill, popup, and dashboard (`TopBarHabitPill.tsx`, `PracticeRecommendations.tsx`, `PracticeApp.tsx`) that serves below-rating `Warmup` picks for today and automatically resets tomorrow.
- Added persistent review & feedback backup:
  - Automatically mirrors compact self-reported outcomes and review history to chunked `browser.storage.sync` and restores them automatically if local extension storage is cleared or reinstalled (`ledgerBackup.ts`, `dataBroker.ts`).
  - Added **Export backup** and idempotent **Import backup** JSON controls to the Dashboard Account panel (`PracticeApp.tsx`).

Firefox and Chrome packages are attached. Firefox installations using automatic updates can move from 2.0.15 to 2.0.16.
