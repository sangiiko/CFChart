## What changed

- Sped up practice syncing after submissions and Wrong Answers:
  - Added incremental 50-submission delta syncs (`INCREMENTAL_PAGE_SIZE = 50`) when full submission history is already complete, falling back to full-page sync only when needed, plus a 5-second `TESTING` verdict TTL so `TESTING → WRONG_ANSWER` settles promptly (`dataBroker.ts`).
  - Added in-flight `getPractice` request coalescing, cached catalog enrichment, a 1-hour cached profile TTL inside `getPractice`, O(N) `syncProblemRecord` pre-indexing, and assisted-only pre-filtering in `selectScheduledReviews`.
  - Scoped `storage.onChanged` listeners (`extensionClient.ts`) to prevent self-triggered refresh cascades across tabs (`TopBarHabitPill.tsx`, `PracticeApp.tsx`), and updated `controller.tsx` to mount `ProblemTimerWidget` immediately without re-querying practice data on unrelated DOM mutations.

Firefox and Chrome packages are attached. Firefox installations using automatic updates can move from 2.0.14 to 2.0.15.
